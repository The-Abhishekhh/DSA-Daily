🧠 My Problem-Solving Process

For every problem, I try to follow this process:

1. Understand

- What exactly is being asked?
- What are the constraints?
- What edge cases exist?

2. Brute Force

First understand the straightforward solution.

3. Optimize

Ask:

«"What repeated work can I eliminate?"»

Then look for:

- Hashing
- Two pointers
- Sliding window
- Binary search
- Heap
- Greedy
- Dynamic programming
- Graph algorithms
- Other applicable patterns

4. Implement

Write the solution in Java.

5. Analyze

Document:

Time Complexity: "O(?)"

Space Complexity: "O(?)"

6. Revisit

Problems that I struggle with are revisited later instead of being considered "done" after one accepted submission.

📌 Important Principles

- Don't memorize solutions.
- Understand the underlying pattern.
- Always consider the brute-force approach first.
- Optimize based on constraints.
- Write clean Java.
- Know the complexity of your solution.
- Revisit problems you couldn't solve independently.
- Don't be afraid of Hard problems.
- Focus on progress, not perfection.
